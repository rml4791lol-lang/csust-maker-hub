# 信息架构精简（2026-10-28）

> 背景：站点原定位是「内部知识库 + 内容运营平台」，页面多、信息杂。协会真实需求只有两条：
> **1）展示协会的活动与成果；2）收集并分析每位成员做过的事，总结能力才干。**
> 本次按这两个目标做减法，并补上 AI 分析的自动化。

## 一、删减清单

| 原页面 | 处理 | 原因 |
|---|---|---|
| `/library` + `/library/<id>`（31 个详情页） | 下线 | 知识库内容与协会展示目标无关；历史数据保留在 `content/items.json`，继续作为成果回填来源 |
| `/tools` 工具站 | 下线 | 面向内部工具导航，展示场景用不上 |
| `/resources` 下载资源 | 下线 | 模板下载与「活动成果 / 成员能力」无关 |
| `/stats` 数据看板（含值班表） | 下线 | 内部运营数据，与展示目标重复且信息噪音大；能力数据已并入成员页 |
| `/about` 关于 | 合并进首页 | 协会介绍、位置、联系方式只需一块，独立页面冗余 |

| 首页「五类内容」bento、内容控制台、工作台、动态流 | 移除 | 内容是旧定位的产物；首页改为「活动成果 + 成员能力 + 关于协会」三段式 |

页面数：52 → 17（首页 1 + 活动成果 1 + 成员能力 1 + 个人档案 12 + 提交 1 + 404 1 = 17）。

## 二、保留与强化

- **首页**：协会名 + 位置（云塘校区 · 科创港）、定位文案、最近活动与成果、成员能力概览（Top 4 档案 + 高频标签）、关于协会与联系方式、提交入口。
- **活动与成果**：团队成果合并（同一条目多位参与人只出现一次）、类型 / 部门 / 关键词筛选、统计条（条目 / 成员 / 部门 / 最近更新）、配图支持。
- **成员能力**：能力总览（部门产出、成果类型、高频标签、贡献榜）+ 12 位成员卡片；个人档案页保留 AI 汇总面板 + 成果时间线。
- **提交记录**：成员自己填写；授权勾选、配图、审核留痕。
- **后台**：成员投稿面板（发布 / 退回写原因）、AI 汇总重算按钮、审核接口。

## 三、AI 分析自动化（本次新增）

```
成员提交成果 → 后台审核发布
  → 后台自动重算 content/profiles.json（规则分析，毫秒级）
  → 重新构建后：个人档案 AI 面板 / 成员能力总览 / 贡献榜同步更新
```

- 规则分析：`src/data/analyze.ts`（关键词能力标签 + 成果类型权重 + 代表成果 + 下一步建议）
- LLM 增强：服务器配置 `AI_API_KEY` / `AI_BASE_URL` / `AI_MODEL` 后，`pnpm analyze` 与后台「重算 AI 汇总」自动走 LLM，失败回退规则分析
- 命令：`pnpm analyze`（手动重算）、`pnpm backfill`（从历史内容回填成果）
- 接口：`POST /api/analyze`（需登录 / agent token）立即重算，返回 `mode: llm|rules`

## 四、真实数据接入点（后续替换）
