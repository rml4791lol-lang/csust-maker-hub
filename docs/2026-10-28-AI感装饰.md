# 「AI 感」装饰视觉（2026-10-28）

为了让页面有一点 AI 实验室 / 科技产品的气质，但又不干扰阅读，新增了一组**程序化生成**的抽象装饰图。
没有使用任何外部素材，也就没有版权问题；全部可复现。

## 一、素材清单（`public/decor/`）

| 文件 | 内容 | 用在哪 |
|---|---|---|
| `orbit.webp` | 发光轨道环 + 粒子 + 中心十字（1800×1800，74KB） | 首页首屏背景（右下角，缓慢旋转） |
| `mesh.webp` | 线框波纹网格（2200×846，93KB） | 首页首屏底部渐隐、全站页脚 |
| `neural.webp` | 神经网络节点连线（1700×1000，97KB） | 各页面页头、CTA 区（暗色遮罩下低对比） |
| `aurora.webp` | 极光色块柔光（1800×1064，17KB） | 首页首屏文案后的柔光 |

生成脚本：`scripts/generate-decor.py`（numpy + Pillow，纯本地可复现）。
用法：`python scripts/generate-decor.py`（改颜色/密度直接改脚本顶部常量）。

## 二、使用原则（已写进 CSS 与 AGENTS）

- **只做点缀**：装饰图不承载信息，全部 `pointer-events: none`，`aria-hidden` 语义上等同背景。
- **低对比**：页头/CTA/页脚用「暗色渐变遮罩 + 图片」叠加，避免抢正文；首屏装饰 opacity 0.5 左右并 `mix-blend-mode: screen`。
- **不挡内容**：首屏装饰层 `z-index: 0`，内容 `z-index: 1`；轮播上加极轻的扫描线动画。
- **尊重动效偏好**：`prefers-reduced-motion: reduce` 时关闭旋转与扫描动画。
- **小屏收敛**：≤860px 关闭页头/CTA/页脚装饰，首屏装饰缩小并降透明度。

## 三、如果以后要换成「AI 生成的图片」

当前装饰是程序化生成的，好处是稳定、无版权风险、体积极小。若以后想换成 Midjourney / SD 等模型生成的图：

1. 把图导出为宽屏 webp（建议 ≤200KB），放 `public/decor/`；
2. 替换 CSS 里对应 `url('/decor/xxx.webp')`；
3. 保持低透明度与暗色遮罩，别盖过正文；
4. 画面里不要出现可识别的真人、品牌 logo、文字（避免版权与隐私问题）。
