# 设计合并：association-os 前端风格（2026-10-28）

## 背景

技术部另一位成员开发了 `association-os`（Next.js 原型，本地预览 `127.0.0.1:3100`，源码在 `.dsh-preview/csust-maker-hub/apps/association-os`，该目录不参与本仓库提交）。本次把它的**前端视觉语言与组件形态**合并进本站（Astro），保留本站的内容、信息架构与功能（投稿、上传、审核、成员档案、管理端）。

## 合并后的设计系统

| 维度 | 取值 |
| --- | --- |
| 布局 | 左侧固定侧边栏 240px + 顶部粘性工具栏 64px + 内容区（最大 1440px） |
| 底色 | `#090d14`；面板 `#111925` / `#172230` / `#1e2c3d` |
| 文字 | 主 `#edf3fa`、次 `#a1afbf`、弱 `#93a3b7`；标题黑体 |
| 强调色 | 蓝 `#5797ff`（主）+ 青 `#50d6e8`（强调） |
| 语义色 | 成功 `#4ade80`、警告 `#fbbf24`、危险 `#f87171` |
| 字体 | 标题/正文 Noto Sans SC；叙述宋体 Noto Serif SC；元数据 JetBrains Mono；数字 Times + tabular-nums |
| 面板 | 8px 圆角、1px 描边、顶部受光渐变 + 双层投影；悬停上浮 2px |
| 首屏 | 冷蓝渐变 stage + 程序化 3D 线框（three.js，桌面/允许动效时启用，移动端与 reduced-motion 用静态几何线框兜底）+ 右侧玻璃「最近成果」面板 |
| 数据概览 | 四列 bordless 统计行（大号衬线数字） |
| 动效 | 入场 reveal、数字滚动、悬停微交互；全部尊重 `prefers-reduced-motion` |
| 响应式 | ≤1024px 收起侧栏改顶部抽屉导航；≤640px 单列 |

## 合并时保留的本站规则

- 只保留 5 个主导航入口（首页 / 活动与成果 / 成员能力 / 现场相册 / 提交记录）+ 管理端、登录；**没有**引入对方的全局搜索/命令面板（此前已确认页面太少，搜索是负担）。
- **不展示成员人数**；数据概览改为「活动场次 / 成果条目 / 现场照片 / 覆盖部门」。
- 字体下限：任何页面不小于 14px（对方 UI 偏小，本站按既有规范保持 16px 正文、14px 元信息）。
- 站点仍为静态构建；管理端 `/manage`、上传、审核等功能不变。
- 对方站点里的示例数据、管理后台、数据库等没有合并，仅合并前端风格。
- 旧的装饰图 `public/decor/` 保留但不再在页面使用；页面上的 AI 感装饰由新的线框几何 + 网格 + 光晕承担。

## 实现位置

- `src/styles/app-theme.css`：设计 token 覆盖 + 侧边栏/顶栏外壳 + 面板/按钮/表单/相册/成员档案等组件样式。
- `src/layouts/Base.astro`：新外壳（侧边栏、顶栏、移动端抽屉、登录态）。
- `src/pages/index.astro`：工作台式首页（首屏 + 数据行 + 活动/成果/成员/相册面板 + CTA + 3D 线框场景）。
- `src/pages/achievements.astro` 等页面通过新版 page-header / 面板样式自动套用。
- 依赖新增：`@fontsource-variable/noto-sans-sc`、`@fontsource-variable/noto-serif-sc`、`@fontsource-variable/jetbrains-mono`、`three`。


## 首页再收敛（2026-10-28）

在合并风格后，首页进一步做极简：

- 只保留 **首屏** 与 **精选成果** 两段。数据概览、活动面板、成员面板、相册面板、大 CTA 全部撤掉（对应信息去各自页面看）。
- 首屏：左侧一句话标题 + 一行介绍 + 两个入口；右侧只放背景层次，不放数据面板。
- 背景三层叠加：光晕（最底）→ 64px 网格 → 线框环 + 3D 线框（最上、最亮）；后层低对比、前层高对比，形成纵深。
- 精选成果：窄容器、无卡片、行式列表（编号 / 标题 / 类型 / 箭头），行悬停轻微右移，强化层级。
- 移动端：隐藏 3D canvas（reduced-motion 同理），保留静态线框环；精选行隐藏类型标签。
