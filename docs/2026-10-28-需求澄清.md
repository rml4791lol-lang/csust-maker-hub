# 需求澄清与分期计划（2026-10-28 讨论定稿）

> 本站目标：展示长沙理工大学 AI 创客协会的活动与成果，并收集、分析每位成员做过的事，形成能力档案。
> 本文件记录 2026-10-28 需求讨论的最终决定，作为后续迭代依据。

## 一、已定决策

| 模块 | 决定 |
|---|---|
| 受众 / 收录 | 内部先用，全站 `noindex`，暂不开放搜索引擎收录 |
| 投稿身份 | **实名制账号**：成员自助注册，管理员审核通过后生效；登录后投稿，身份自动带出 |
| 隐私 | 档案展示「姓名 + 部门 + 能力标签」，**年级默认隐藏**（数据保留） |
| AI 汇总 | 公开展示，含「成长方向 / 下一步建议」；**使用规则分析自动生成（无需 LLM Key）** |
| 图片 / 相册 | 做**后台上传工具** + 活动相册展示（上传权限：部长及以上） |
| 分享 | 首页 + 成员档案的分享卡片（`og:image`） |
| 招新 | 暂不加「加入我们」入口，招新时再加 |
| 旧内容库 | 以后以轻量「资料库」形式回归（backlog，不阻塞当前） |
| 成员数据 | 先用占位名单把功能跑通，真实名单到位后替换 `src/data/members.ts` 并重跑 `pnpm analyze` |

## 二、分期计划

### A. 分享卡片 + AI 自动跑收尾（已完成）

- 首页分享图 `public/share/home.jpg`；每位成员专属分享图 `public/share/member-mXX.jpg`（1200×630）。
- `Base.astro` 新增 `shareImage` 参数，输出 `og:url / og:image / og:image:width / og:image:height / twitter:card`。
- 生成脚本：`python scripts/generate-share-cards.py`（Pillow，可复现）。
- 隐私：成员档案、成员列表、首页成员卡不再显示年级。
- AI 规则分析自动跑：后台审核发布投稿后自动重算档案；后台启动时若「投稿比档案新」也会自动重算；`pnpm analyze` 与 `POST /api/analyze` 可手动触发。

### B. 实名账号系统（已完成，2026-10-28）

范围：

1. `/join` 或 `/register`：成员自助注册（姓名、部门、角色、密码；姓名与名单核对）。
2. 管理员在后台「账号审核」：通过 / 拒绝；通过后账号可登录。
3. `/login`：账号密码登录（HttpOnly cookie，7 天有效），支持退出、改密码。
4. `/contribute`：必须登录，身份自动带出；不再手选成员名。
5. 「我的投稿」：查看自己的投稿与审核状态，可修改/撤回待审核记录。
6. 角色与权限：普通成员 / 部长 / 管理员；为 C 的上传权限做准备。
7. 后台：批量导入名单开户、重置密码、禁用账号。

技术要点：账号数据存服务器本地（不提交仓库）、密码 scrypt 哈希、登录限流、会话签名密钥来自 `DATA_DIR`/`.env.admin`。

实现说明：`/register` 自助注册（姓名+部门匹配名单）→ 后台「成员账号」审核并核定角色 → `/login` 登录（HttpOnly cookie 7 天）→ `/contribute` 登录后提交（身份来自账号）→「我的投稿」可修改/撤回；后台支持重置密码。本地开发通过 `astro.config` 的 `/admin` 代理联调。

### C. 后台上传 + 活动相册

1. 登录后的部长/管理员可在后台给活动上传封面与现场照片（大小限制、格式校验、自动压缩）。
2. 活动页相册：多图展示、点击放大。
3. 上传后写回 `content/activities.json` 与 `public/photos/uploads/`，重新构建生效。
4. 依赖 B 的角色权限与上传目录（服务器写权限）。

### D. Backlog（不阻塞）

- 轻量「资料库」回归（对应纪要里的线上技术分享 / 资料沉淀职责）。
- 招新入口与报名表单（招新前再加）。
- LLM 分析升级（服务器配 `AI_API_KEY` 后自动切换，失败回退规则分析）。

## 三、开放问题（不阻塞 A）

- 真实成员名单（替代占位数据）——B 上线前需要。
- 上传图片的存储配额与备份策略——C 上线前确认。
- 注册时的实名核对方式（姓名 + 部门与名单匹配？需学号后四位？）——B 设计时确认。

## 四、验收口径

- A：`pnpm test` 通过（含分享图校验）、`pnpm build` 通过、烟雾检查含 `og:image` 校验；微信/社交平台链接预览显示分享图。
- B：未登录不能投稿；注册需审核；登录后只能看到自己的投稿；改密/退出正常。
- C：部长可上传图片并在活动页看到相册；非法格式/超大文件被拒绝。
