# 本机管理员账号

公开页面无需登录。点击「编辑内容」或足迹页「记一条」才要求登录。只有一个管理员账号；没有成员注册，也没有默认密码。

本机预览未配置账号时，可以通过独立的本机初始化页自己创建。正常 Next.js 服务没有公开初始化 API。初始化辅助进程只绑定 `127.0.0.1:3190`，核验网络连接、Host、Origin 和页面随机令牌，拒绝代理转发请求；创建后自动关闭。

在应用目录的两个 PowerShell 终端使用同一个隔离数据路径：

```powershell
$env:AI_ASSOCIATION_DATA_DIR = 'D:\path\to\preview-data'
$env:AI_ASSOCIATION_ALLOW_LOCAL_SETUP = '1'
$env:ADMIN_USER = ''
$env:ADMIN_PASSWORD = ''

# 终端一：新版预览
pnpm dev --hostname 127.0.0.1 --port 3100

# 终端二：使用相同环境变量启动一次性初始化页
node --experimental-strip-types scripts/setup-admin.ts
```

打开 <http://127.0.0.1:3100/>，点击「编辑内容」→「创建本机管理员账号」。在新页面输入账号、密码和确认密码。创建后返回预览，用刚才的账号登录。账号 3–64 位；密码至少 12 个字符。

账号文件在数据目录的 `admin-auth/account.json`：只保存 scrypt 密码哈希与随机会话签名材料，不保存明文密码。Linux/macOS 限制目录/文件权限；Windows 初始化将认证目录 ACL 限制为当前用户。文件使用独占、原子方式发布，已存在时不会覆盖。不要提交整个数据目录、账号文件或附件到 Git。

如果启动环境包含 `ADMIN_USER` 或 `ADMIN_PASSWORD`，以环境配置模式为准，两项齐全才启用登录，本机初始化始终关闭。服务器使用既有环境配置；不要在服务器上启用本机辅助初始化。账号忘记时由本机负责人在停止服务后处理凭据备份和重置，不提供匿名找回或远程重置入口。

会话一小时过期。编辑过程中到期，会保留表单并提示重新登录；登录后需要再次点击保存/发布，不会自动重放写请求。退出后返回公开首页。
