# 二三级页面交接

2026-10-28，本地实现。当前改动尚未推送到协作仓库或部署到服务器；不要把本地文档当作线上能力证明。

## 页面链路

下列模块均提供 `/<模块>` 列表、`/<模块>/<id>` 详情、`/<模块>/new` 新增、`/<模块>/<id>/edit` 编辑。

| 模块 | 路径 | 详情内容 |
|---|---|---|
| 项目 | projects | 当前阶段、说明、负责人 |
| 内容库 | library | 摘要、纯文本正文、来源、标签 |
| 成员 | members | 部门、角色、年级、技能 |
| 竞赛 | competitions | 主办方、截止、登记队伍、参赛成员 |
| 活动 | activities | 时间、地点、人数与名额 |
| 成果 | achievements | 所属赛事、获奖成员、证书登记状态 |
| 足迹 | footprints | 完成记录、投入时间、项目与已有附件 |

浏览列表和公开详情不要求登录。新增/编辑触发管理员认证；直接访问编辑地址也不提前读取私有记录。只有内容库公开白名单状态和 approved 足迹可以公开阅读。不存在或未公开记录使用同一未找到界面，Next 流式响应的 HTTP 状态可能已发送为 200，不能只按状态码判断数据是否泄露。

每条内容均保留真实缺失状态：没有正文就提示尚未补充，没有证书文件不提供下载，未实现线上报名不显示可报名按钮。无年份日期明确待核验，不推断属于今年。示例数据继续由全站提示标识。

## 统一视觉入口

- `src/app/globals.css`：颜色、文字、页面宽度、detail-* 布局、移动端响应。正文 16px，必要辅助文字至少 14px。
- `src/components/page-header.tsx` 与 `geometry-mark.tsx`：同源标题与几何线框，不向正文堆叠装饰。
- `src/components/record-detail.tsx`：宽正文、窄事实栏；窄屏默认事实栏在前，内容库/足迹优先正文、活动优先时间地点。仅针对真实字段分模块组织。
- `src/components/record-editor.tsx`：分组表单、字段错误、保存、取消、未保存保护和重新认证。
- `src/components/edit-record-button.tsx`：按需登录与编辑目标。
- `src/lib/content-modules.ts`：导航名、实体名、路由与枚举显示。

以后整体视觉升级优先修改这些共享入口，再逐模块检查差异。保持偏左 Hero 构图及原几何，不添加装饰小字、英文眉题、编号、发光圆点或卡片套卡片。无特定任务不更换技术栈。

## 数据和迁移

迁移 v4 在原有结构上增加 `projects.id`、`projects.description`、`items.body`、`items.source_url`，给已有项目补充稳定 ID。唯一索引和触发器确保标识完整且不可修改。旧名称主键保留兼容，迁移有事务与幂等测试。

项目改名与足迹精确文本关联更新在同一事务完成；不根据相似名称推测关联。公共查询使用明确字段投影；内容公开状态和链接协议在服务端校验。编辑 API 继续执行认证、来源校验和状态转换规则。

上线前先停止写入、备份完整 SQLite 数据目录及 `data/uploads/`，在隔离副本跑迁移并核对数量、状态、ID 和附件。不对真实数据运行回归测试。回滚需停止服务并同时恢复已备份的代码与数据，不能直接在生产删除新增列或回退迁移版本。当前预览使用隔离数据，尚未实施旧站内容迁移和生产恢复演练。
