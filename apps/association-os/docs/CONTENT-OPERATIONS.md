# 录入与修改内容

从网站导航进入「发布中心」`/publish`，选择模块后新增或编辑。公开列表和详情仅用于浏览，维护时才需要管理员登录；尚无本机管理员时按 [本机账号初始化](LOCAL-ADMIN.md) 创建。初始数据库包含示例，不能当作真实运营名单。

| 模块 | 当前可改字段 |
|---|---|
| 成员 | 姓名、部门、角色、年级、技能（逗号分隔） |
| 内容 | 标题、类型、主题、作者、摘要、正文、来源链接、标签、状态、更新日期 |
| 项目 | 名称、负责人、项目说明、状态、更新日期 |
| 竞赛 | 名称、级别、主办方、状态、截止、队伍数、参赛成员 |
| 活动 | 标题、类型、时间、地点、状态、报名人数、名额 |
| 成果 | 奖项、级别、所属赛事、获奖成员、日期、有无证书 |
| 足迹 | 成员、做了什么、关联项目、耗时、状态、日期 |

足迹材料入口在 `/publish/footprints` →「记录并上传材料」，管理员可附不超过 5 MB 的图片或 PDF。该入口提交即公开；通用“新增足迹”仍按 draft→pending→approved 流转。姓名由管理员填写，不代表成员身份认证。

社区文章只有「已发布、已收录、报名中、已归档」对外展示。新文章支持图文编辑、格式工具栏、选择/粘贴图片和预览；旧正文保持纯文本，需主动启用图文。正文图片上传到当前数据目录，并按文章公开状态控制访问。来源与正文链接仅接受 HTTP(S)。草稿和公开内容保存后都留在维护区，公开内容可点击「查看公开页」。离开未保存内容会提醒，登录过期保留输入，重新登录后手动保存。

Hero 标语、官网介绍及固定照片在源码中维护，目前没有站点文案管理表。图文上传的权限和备份见 [媒体存储](MEDIA-STORAGE.md)。


项目使用稳定 ID 链接，改名不会改变详情地址；管理 API 同步足迹中与旧项目名称完全相同的关联文本。其他自由文本不进行推断匹配。清空已有数据不是录入的必要步骤；不要随意使用后台清空功能。正式资料导入前先完成字段、权限和备份流程。

七条页面链路、共享组件和迁移说明见 [页面系统交接](PAGE-SYSTEM.md)。
