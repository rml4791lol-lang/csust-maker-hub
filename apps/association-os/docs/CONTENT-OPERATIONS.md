# 录入与修改内容

管理员配置完成后打开 /admin，登录，选择模块 → 新增或编辑 → 保存 → 前台刷新核对。默认数据库是示例数据；仓库不包含真实名单、现有数据库或密码。

| 模块 | 当前可改字段 |
|---|---|
| 成员 | 姓名、部门、角色、年级、技能（逗号分隔） |
| 内容 | 标题、类型、主题、作者、摘要、标签、状态、更新日期 |
| 项目 | 名称、负责人、状态、更新日期 |
| 竞赛 | 名称、级别、主办方、状态、截止、队伍数、参赛成员 |
| 活动 | 标题、类型、时间、地点、状态、报名人数、名额 |
| 成果 | 奖项、级别、所属赛事、获奖成员、日期、有无证书 |
| 足迹 | 成员、做了什么、关联项目、耗时、状态、日期 |

普通足迹入口是 /footprints →「记一条」，可以附不超过 5MB 的图片或 PDF。当前无需登录、提交即公开；姓名由提交人填写，不能据此认证身份。后续编辑和删除由管理员处理。

内容库“状态”不是保密开关：当前公开查询不按此字段过滤；请勿用“草稿”保存私有资料。内容库目前管理摘要条目，还不能发布完整长文。Hero 标语和部分页面说明在组件里修改，后台暂无站点文案配置。

项目改名后，其他记录里的文本关联不会自动保证同步。清空已有数据不是录入的必要步骤；不要随意使用后台清空功能。正式资料导入前先完成字段、权限和备份流程。
