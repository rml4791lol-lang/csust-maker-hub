# 招新海报生成

## 什么时候用
- 开学招新、部门纳新
- 活动宣传需要统一视觉

## 输入
1. 招新对象（年级、专业）
2. 想突出的一句话卖点
3. 时间地点
4. 现有素材（logo、往期照片）

## 输出结构
```
标题：一句话，不超过 12 字
副标题：补一句为什么来
三个卖点：每个不超过 15 字
行动信息：时间 / 地点 / 报名方式
视觉：主色 + 一张主图方向
```

## 注意
- 不要写"欢迎加入我们"这种空话
- 卖点要具体：能学到什么、能做什么、能拿到什么
- 二维码放右下角，留白 ≥ 8mm
