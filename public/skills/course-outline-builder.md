# 课程大纲生成

## 什么时候用
- 准备一次技术分享或工作坊
- 需要把"我会"变成"别人能学会"

## 输入
1. 主题
2. 听众基础
3. 时长
4. 希望学员带走什么

## 输出模板
```
课程名：动词 + 对象
学完能做什么：（一句话，具体动作）
前置要求：
大纲：
  1. 引入（问题场景，5 分钟）
  2. 核心步骤（边讲边做）
  3. 常见错误
  4. 练习（改一个小地方）
现场产出：一个能跑的东西 / 一份材料
```

## 判断标准
学员照着做完，能自己复现一遍。
