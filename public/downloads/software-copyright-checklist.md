# 软著申请材料清单

## 一、基本信息
- 软件全称（含版本号）：
- 开发完成日期：
- 首次发表日期：
- 权利取得方式：原始取得
- 开发者：

## 二、需要准备的材料
1. 软件著作权登记申请表（官网在线填）
2. 源程序（前后各连续 30 页，共 60 页；不足 60 页全交）
   - 每页不少于 50 行
   - 页眉标注软件名称和版本号
   - 最后一页为程序结尾
3. 文档（用户手册 / 设计说明书，前后各 30 页）
4. 身份证明（学生：身份证 + 学生证）
5. 合作开发协议（多人时）

## 三、常见退回原因
- 源程序页数不足 / 行数不够
- 页眉没有软件名称和版本号
- 文档与程序功能对不上
- 软件名称含"系统""平台"但材料体现不出
- 版本号格式错误（应为 V1.0 这种）

## 四、时间预期
- 正常审查：30~60 个工作日
- 加急：另计，需要额外费用
