# 需求登记表模板

| 字段 | 说明 | 必填 |
|---|---|---|
| 需求标题 | 一句话说清要做什么 | 是 |
| 提出部门 | 技术部 / 竞赛部 / 宣传部 / 创新创业部 / 其他 | 是 |
| 提出人 | 姓名 + 联系方式 | 是 |
| 要解决什么问题 | 现在怎么做的、卡在哪 | 是 |
| 期望结果 | 希望变成什么样 | 是 |
| 期望时间 | 什么时候要 | 否 |
| 可提供的素材 | 参考链接、现有文件 | 否 |
| 是否紧急 | 是 / 否，以及原因 | 否 |

## 处理流程
1. 提交后 1 个工作日内回复能不能接
2. 确认后约定交付时间
3. 交付后记录一条可复用的产出
